# Информатика для первокурсника

## Название

Мини-справочник «Информатика для первокурсника».

## Цель

Помочь первокурснику быстро разобраться в базовых темах информатики и научиться применять их на практике.

## Автор

Студент, псевдоним: Azalia

## Выбранная тема

Системы счисления: двоичная, восьмеричная, шестнадцатеричная, перевод чисел и арифметические операции.

## Список файлов

* README.md — описание проекта и инструкция чтения.
* glossary.md — словарь основных терминов (не менее 8).
* examples.md — разобранные примеры с решениями (не менее 3).
* sources.md — использованные источники с ссылками.
* questions.md — вопросы для самопроверки с ответами.

## Как пользоваться справочником

1. Начните с glossary.md — выучите основные термины.
2. Затем прочитайте examples.md — разберите ход решения.
3. Проверьте себя по questions.md.
4. При необходимости обратитесь к sources.md за подробностями.

## Как читать примеры

В каждом примере указаны исходные данные, ход решения и ответ. Рекомендуется сначала попробовать решить самостоятельно, а затем сверить с разбором.



\## Порядок чтения

Рекомендуемый порядок: glossary.md → examples.md → questions.md → sources.md.
